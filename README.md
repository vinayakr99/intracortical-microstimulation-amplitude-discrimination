# intracortical-microstimulation-amplitude-discrimination

This repository contains the model and data analysis code associated with the paper:

E. Su, V. Retheesh, K. Kumaravelu, S. Sharma, W. M. Grill and K. Otto (2026) 
Ultra-Micro Electrodes Support Low-Current Amplitude Discrimination in Intracortical Microstimulation.

This model was contributed by K. Kumaravelu and V. Retheesh. For questions regarding the model or code, please contact vinayak.retheesh@duke.edu .

MODEL DESCRIPTION

The modeling pipeline consists of the following components:

1. Finite Element Model (FEM)

The FEM generates the three-dimensional extracellular potential distribution resulting from electrical stimulation. The FEM was implemented in COMSOL Multiphysics version 6.3 and consists of a custom 'G1' microelectrode array (MEA) embedded in a cortical column. The solved three-dimensional potentials are interpolated at the coordinates of all neuronal components. All necessary files and instructions for running the FEM simulations are provided in the "COMSOL_FEM" folder.

2. Cortical Column Model

The cortical column model computes neuronal responses to electrical stimulation. The model comprises 6,410 neurons across 25 cell types and was implemented in NEURON version 7.6. The interpolated FEM potentials are coupled to the model neurons using the extracellular mechanism and scaled according to the stimulation waveform. The resulting transmembrane potentials are used to compute neuronal spike times. All necessary files and instructions for running the NEURON simulations are provided in the "NEURON_Simulations" folder.

3. Neural Activation Analysis and Discrimination Threshold Estimation

The spike-time data generated by the NEURON simulations are analyzed to compute higher-level measures of neural activation, including activation distances, activated cell IDs, and spike counts. Discrimination thresholds are estimated by fitting the model-derived activation data to the experimental data using different neural activation metrics.

MODELING PIPELINE

The modeling pipeline should be executed in the following sequence:

1. COMSOL_FEM

Follow the instructions provided in the "COMSOL_FEM" folder. For each electrode depth condition:

- Generate the coordinates of the neuronal components.
- Run the COMSOL FEM simulations for each contact diameter.
- Interpolate the FEM potentials at the generated neuronal coordinates.
- Format the interpolated potentials for use in the NEURON simulations.

The resulting FEM-interpolated potential files are used as inputs to the NEURON simulations.

2. NEURON_Simulations

Follow the instructions provided in the "NEURON_Simulations" folder. For each contact diameter within each depth condition:

- Import the corresponding FEM-interpolated potentials.
- Run the cortical column simulations in NEURON.
- Export the resulting neuronal spike-time data.

The spike-time data are used as inputs for the neural activation analysis.

3. Results

Follow the instructions provided in the "Results" folder. For each contact diameter within each depth condition:

- Import the corresponding spike-time data.
- Compute neural activation measures, including activation distances, activated cell IDs, and spike counts.
- Perform discrimination threshold estimation by fitting the model-derived activation data to the experimental data.
- Generate the results corresponding to Figures 6, 7, and 8, and Supplementary Figures S3, S4, S5, S7 and S8 in the paper.

SOFTWARE REQUIREMENTS

- COMSOL Multiphysics 6.3
- NEURON 7.6
- MATLAB R2022b

FOLDER STRUCTURE

- COMSOL_FEM/ : COMSOL FEM models, neuronal coordinate generation, potential interpolation.
- NEURON_Simulations/ : NEURON cortical column model, simulation scripts, and spike-time extraction.
- Results/ : MATLAB scripts and data-analysis procedures for neural activation analysis and discrimination threshold estimation.

DATA AVAILABILITY

The code and model files required to reproduce the simulations are provided in this repository. The processed data used to generate the results figures are also provided in the Results/ directory. The data are organized by depth condition under the following directories:

- Results/Reference_Depth/activation_data_ConvexHull/
- Results/Depth_down150um/activation_data_ConvexHull/
- Results/Depth_up150um/activation_data_ConvexHull/

The complete modeling pipeline can be reproduced by following the instructions in the COMSOL_FEM, NEURON_Simulations, and Results folders in the order specified above.

Alternatively, the final results figures can be generated using the provided processed data by directly following STEP 3 and STEP 4 in Results/README.txt
