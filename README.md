# intracortical-microstimulation-amplitude-discrimination
Model and  data analysis code for E. Su, V. Retheesh, K. Kumaravelu, S. Sharma, W. M. Grill &amp; K. Otto (2026), “Ultra-Micro Electrodes Support Low-Current Amplitude Discrimination in Intracortical Microstimulation.” Includes COMSOL FEM, NEURON simulations, and neural activation data analysis.
